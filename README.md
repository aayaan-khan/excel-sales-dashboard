#  Ferns & Petals Sales Analysis Dashboard

## Project Overview

This project presents an **end-to-end Sales Analysis Dashboard** built entirely in **Microsoft Excel Online** for **Ferns & Petals (FNP)**. The dashboard transforms raw sales data into meaningful business insights through data cleaning, data modeling, KPI development, Pivot Tables, Pivot Charts, and interactive dashboard design.

The primary objective is to provide decision-makers with an interactive reporting solution to monitor business performance, identify sales trends, analyze customer behavior, evaluate product performance, and support strategic decision-making.

---

#  Business Problem

Ferns & Petals generates thousands of customer orders across multiple occasions, products, and cities. Without a centralized reporting system, it becomes difficult to answer important business questions such as:

- Which months generate the highest revenue?
- Which occasions contribute the most sales?
- Which products are top performers?
- Which cities generate the most orders?
- Who are the highest-value customers?
- How efficient is the delivery process?

This dashboard addresses these questions through interactive visualizations and KPI tracking.

# Dataset Information

The project uses three relational datasets.

## Orders Dataset

Contains transactional information such as:

- Order ID
- Customer ID
- Product ID
- Quantity
- Order Date
- Delivery Date
- Order Time
- Delivery Time
- Occasion
- Location

---

## Customers Dataset

Contains customer information including:

- Customer ID
- Customer Name
- City
- Contact Number
- Email
- Gender
- Address

---

## Products Dataset

Contains product-related information:

- Product ID
- Product Name
- Category
- Price
- Occasion
- Description
